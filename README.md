# RMF2 Data Broker

Data broker for RMF2 microservices.
This repo contains common infrastructure and services for communication and connectivity.

> An older version ([`legacy` branch](https://github.com/ros-industrial/rmf2_broker/tree/legacy)) serves as a proof-of-concept.
>
> A future stable version is under active development,
> the progress can be tracked under the current branch.
> For more info, please checkout <https://github.com/ros-industrial/rmf2_broker/issues>.
